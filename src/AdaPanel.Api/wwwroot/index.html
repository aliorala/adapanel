Panel açılamadı

Panel arayüzü yüklenemedi. En sık sebebi, güncelleme sonrası tarayıcıda kalan eski sayfa dosyasıdır.

  1. Sayfayı sert yenileyin: Ctrl + F5 (Mac: Cmd + Shift + R)
  2. Düzelmezse tarayıcı önbelleğini bu site için temizleyin.
  3. Yine açılmazsa sunucuda AdaPanel servisini yeniden başlatın.
