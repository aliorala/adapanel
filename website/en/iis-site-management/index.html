Publishing an IIS website with AdaPanel

AdaPanel brings IIS website paths, domain bindings and SSL certificates into one interface on your Windows server. A working deployment requires the application, IIS, DNS and external connectivity to agree.

What should you decide before creating a site?

Identify the domain, application publish directory and required runtime. The IIS document root should contain files intended for public access. Keep source files, .env files, database backups and private keys outside the public document root.

Create the site and domain binding in AdaPanel, then configure the components your application requires. PHP versions, ASP.NET requirements and separate application processes depend on the project. Installing the panel does not establish that every application dependency is ready.

How do DNS records differ from IIS bindings?

A DNS A record directs a visitor to the server’s public IPv4 address. An IIS binding selects which site handles the incoming request. Behind NAT, the local IIS address and the public DNS address may differ; do not use them interchangeably.

If both example.com and www.example.com will be used, prepare DNS, IIS bindings and certificate coverage for both names. Choose a primary address and permanently redirect the other. A canonical tag cannot repair a missing HTTPS binding.

How should you verify HTTPS?

  1. Check that the domain resolves to the correct server.
  2. Confirm HTTP and HTTPS reach the intended IIS site, including ports 80/443 when using NAT.
  3. Issue or bind the certificate from AdaPanel’s SSL section.
  4. Open HTTPS using the domain from another network. Validate the hostname, certificate chain and expiry.
  5. Check that HTTP redirects to the chosen HTTPS address and that pages and assets load.

Common deployment symptoms

SymptomFirst check
A different site opensDNS destination and IIS hostname binding
HTTPS shows a certificate warningCertificate SANs, intermediate chain and the certificate actually served
The application returns 500Application logs, runtime, permissions and connection settings
Works locally, fails externallyNAT, firewall, public IP and provider restrictions

Checks before switching traffic

Test login, uploads and database operations through the real domain. Confirm a missing address returns 404. Restore a backup into a separate test site and run it; keep the previous deployment until the DNS transition is complete.

Frequently asked questions

Does AdaPanel provide hosting or a server?

AdaPanel is management software installed on your own Windows server. The server, internet connection and domain are supplied separately.

Link to this answer

Does an SSL certificate also cover www?

Only if the certificate includes the www hostname. DNS and the IIS binding must also be configured correctly.
