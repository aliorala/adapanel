Features

Everyday server management in one place

Manage web, mail and database services through a shared interface. Install and configure the components your workloads need.

Websites

IIS sites; PHP, ASP.NET, Node.js, Python; document root, URL rewrite and one-click WordPress.

Mail

Domains, mailboxes and aliases with Stalwart and Roundcube; setup and checks for SPF, DKIM and DMARC records.

Databases

MySQL, MariaDB, PostgreSQL and MSSQL; phpMyAdmin, users/grants and remote access.

SSL Certificates

Free, auto-renewing HTTPS with Let's Encrypt — for sites, webmail and mail.

DNS

Live record synchronization with Windows DNS, templates and private/public IP mapping for NAT. Repair adds missing records; resetting defaults is a separate action.

FTP / Files

Isolated FTP users (FTPS), file manager and per-site permissions.

Migration

Migration workflows for files and databases from Plesk, cPanel or a server. Test the migrated application and backup restoration before changing DNS.

Security

Tenant isolation, firewall, WAF, protected directories and a hidden login path.

Backups & Updates

Scheduled backups, off-site targets, one-click restore and one-click panel updates.

Frequently asked questions

What is AdaPanel?+

AdaPanel is a hosting control panel you install on your own Windows Server. It manages IIS websites, email, databases, DNS, SSL and FTP in one interface. It does not provide a server or hosting service.

Who is AdaPanel for?+

AdaPanel is designed for developers, agencies and administrators hosting sites on Windows and IIS. Administrator, reseller and customer roles help separate resources and access.

What do I need to install it?+

You need administrator access to a Windows server, IIS and the components required by your applications. Take a backup before setup; Windows role installation may require a restart. Complete initial panel setup locally on the server.

Can I use a home server or a server behind NAT?+

Yes, but the local IIS address and the public IP used in DNS must be configured separately. Forward the required ports to the correct server. If another web service shares the public IP, plan ports 80/443 with a reverse proxy or a separate IP. Check CGNAT and provider port restrictions as well.

What do the SEO, AEO and GEO tools do?+

SEO covers technical search visibility; AEO focuses on answer systems, and GEO on generative AI systems understanding content. AdaPanel checks titles, canonical URLs, language, robots rules, structured data and readable text, then provides findings and suggested fixes. The audit does not rewrite your site and cannot guarantee rankings or AI citations.

How do I migrate existing sites?+

Use migration workflows to transfer files and databases, then check runtimes, connection settings, mail and SSL. Verify backup restoration and the application in a separate test environment before switching DNS.

Where can I get updates?+

Official installers are published in GitHub releases. Use Settings → Updates in the panel to check for a new version. Back up your data and read the release notes before updating.
