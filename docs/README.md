# AdaPanel belgeleri

AdaPanel, Windows sunucular için bir barındırma kontrol panelidir (ASP.NET Core 8 + Vue 3,
tek EXE olarak dağıtılır).

| Belge | Kime |
|---|---|
| [Kurulum](kurulum.md) | Sunucuyu kuran kişi |
| [Yönetici kılavuzu](yonetici-kilavuzu.md) | Panelin sahibi / sistem yöneticisi |
| [Müşteri kılavuzu](musteri-kilavuzu.md) | Abonelik sahibi son kullanıcı |
| [Yedekleme ve geri yükleme](yedekleme-ve-geri-yukleme.md) | Yönetici + müşteri |
| [Sorun giderme](sorun-giderme.md) | Yönetici |
| [Yönetici parolasını sunucudan belirleme](parola-kurtarma.md) | Panele giremeyen yönetici |
| [Lisans ve aktivasyon](lisans-aktivasyon.md) | Panelin sahibi + lisans sunucusunu yazacak geliştirici |
| [WHMCS modülü](whmcs-modulu.md) | Panelini WHMCS ile satan bayi |

## Bu belgelerin doğruluk kuralı

Buradaki her adım **kaynak koddan ya da kurulum betiklerinden okunarak** yazıldı. Bir davranış
kaynaktan doğrulanamadıysa ya hiç yazılmadı ya da açıkça **"doğrulanamadı"** olarak işaretlendi.

Sebep basit: yanlış belge, belgesizlikten kötüdür. Belgesiz kullanıcı sorar; yanlış belgeye
güvenen kullanıcı sunucusunu bozar.

Belgelerde geçen menü yolları panelin Türkçe arayüzüne göredir
(`frontend/src/i18n/tr.json` etiketleri).
